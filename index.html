01 / Defense R&D

GPS-Denied Navigation → Object Tracking

IoTechWorld Avigation — Defense Swarm Drone Program

25.7 / 40.3 FPSGUI / headless on Jetson Nano
4.5×preprocessing speedup via ARM NEON SIMD
8-state KalmanSORT tracker, Hungarian assignment

Originally assigned to build GPS-denied Visual Inertial Odometry for autonomous return-to-home on a CUAV X7+ flight controller. Designed a closed-loop hardware trigger architecture to remove time-delay from the VIO state vector, and specified sqrtVINS over standard MSCKF so the covariance estimate wouldn't corrupt under the Jetson's 32-bit float precision.

The target camera turned out to lack an exposed hardware STROBE pin — a constraint no software fix could route around. Pivoted the assignment to real-time object detection and tracking: shipped a YOLOv8n TensorRT engine on Jetson Nano, hand-optimized the preprocessing pipeline with ARM NEON SIMD, and built the multi-object tracker on top.

02 / Data Science

Autonomous Vehicle Braking Variability

URA 401, with Akshaj Arora

AUC 0.85across 40,000+ CAN-bus samples
F1 0.35Isolation Forest, best of 3 methods
90% fasterautomated 14-slide report generation

Analyzed 40,000+ synthetic CAN-bus telemetry samples modeled on nuScenes specs across 50 driving scenarios, looking for anomalous braking behavior — the same unsupervised signal-extraction problem that shows up in transaction-level fraud detection.

Combined PELT and CUSUM change-point detection with Isolation Forest, LOF, and Z-Score anomaly scoring. Isolation Forest led on F1, but the AUC tells the real story: the model ranks true anomalies above normal points 85% of the time. Also built an automated report generator (python-pptx) that cut manual reporting time by 90%.

03 / Competitive C++

NFZ-Aware Drone Routing Engine

Goldman Sachs India Hackathon 2026 — 12hr solo contest

C++17STL, jsoncpp, computational geometry
2 NFZ typescircle projection + Liang-Barsky rect clipping
Multi-tripgreedy charging + retry scheduling

Built a delivery-routing engine under a 12-hour clock: circle no-fly-zones solved via projection-based closest-point geometry, rectangle NFZs via Liang-Barsky per-axis slab clipping, and a deadline-weighted nearest-neighbor scheduler for ordering deliveries.

Iterated the score up from a 34/100 baseline through algorithmic upgrades — progressive bundle-size fallback, mid-route charging via greedy nearest-station selection, and a multi-trip retry loop for deliveries that didn't fit the first pass.

04 / Robotics · ROS2

Gesture-Controlled Robotic Arm

Orangewood Robotics — RAI Workshop 2026 · Best Project

8-pass IKiterative geometric solver + FK correction
1€ filter+ joint-level EMA for jitter removal
UDP controllow-latency link to the controller

Built a real-time gesture-controlled UR5e arm simulation in ROS2 — MediaPipe hand tracking (21 landmarks) driving an 8-pass iterative inverse-kinematics solver, with a 1€ adaptive filter and joint-level EMA to kill jitter without adding perceptible input lag.

Added a hysteresis-based mode lock so the arm doesn't flip between TELEOP, AUTO, and STOP on a single ambiguous frame. Recognized as Best Project among all workshop participants.
